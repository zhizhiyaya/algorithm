## Linux简介

### 1. 什么是Linux

Linux是一个开源的类Unix操作系统内核，由林纳斯·托瓦兹(Linus Torvalds)在1991年创建。它具有以下特点：

- **开源免费**：任何人都可以查看、修改和分发源代码
- **安全稳定**：权限管理严格，系统稳定可靠
- **高性能**：资源占用少，运行效率高
- **多用户多任务**：支持多个用户同时使用系统
- **可移植性强**：可运行在各种硬件平台上
- **社区支持**：拥有庞大的开发者和用户社区

### 2. Linux vs Windows vs macOS

| 特性 | Linux | Windows | macOS |
|------|-------|---------|-------|
| 许可 | 开源免费 | 商业付费 | 商业付费 |
| 稳定性 | 非常稳定 | 较稳定 | 很稳定 |
| 安全性 | 高 | 中 | 高 |
| 软件生态 | 丰富（开源为主） | 最丰富 | 丰富 |
| 定制性 | 极高 | 低 | 中 |
| 学习曲线 | 陡峭 | 平缓 | 中等 |
| 服务器市场 | 主导地位 | 较少 | 很少 |
| 桌面市场 | 较少 | 主导地位 | 较多 |

### 3. Linux的应用场景

- **服务器**：Web服务器、数据库服务器、文件服务器
- **云计算**：AWS、Google Cloud、Azure等云平台
- **容器技术**：Docker、Kubernetes
- **嵌入式系统**：路由器、智能手机（Android）、IoT设备
- **超级计算机**：全球Top 500超级计算机几乎全部使用Linux
- **开发环境**：程序员的首选开发平台
- **桌面系统**：日常办公、学习

## Linux发行版

### 1. 主流发行版

#### Debian系

**Ubuntu** - 最适合初学者
- 优点：用户友好、社区活跃、软件丰富
- 适合：桌面用户、初学者、开发者
- 版本：LTS（长期支持）每2年发布一次

```bash

$ lsb_release -a
No LSB modules are available.
Distributor ID: Ubuntu
Description:    Ubuntu 22.04.3 LTS
Release:        22.04
Codename:       jammy
```

**Debian** - 稳定性之王
- 优点：极其稳定、纯粹的开源
- 适合：服务器、追求稳定性的用户
- Ubuntu的上游发行版

**Linux Mint** - 桌面体验优秀
- 优点：开箱即用、界面美观
- 适合：从Windows转向Linux的用户

#### RedHat系

**RHEL (Red Hat Enterprise Linux)** - 企业级
- 优点：商业支持、稳定可靠
- 适合：企业服务器
- 需要购买订阅

**CentOS** - 免费的RHEL克隆（已停止）
- CentOS 8已于2021年停止维护
- 推荐使用Rocky Linux或AlmaLinux替代

**Rocky Linux / AlmaLinux** - CentOS继任者
- 优点：完全兼容RHEL、免费
- 适合：服务器、企业用户

**Fedora** - 最新技术
- 优点：前沿技术、RHEL的上游
- 适合：开发者、技术爱好者

#### 其他

**Arch Linux** - 极简主义
- 优点：滚动更新、高度定制、最新软件
- 缺点：学习曲线陡峭、需要手动配置
- 适合：高级用户、极客

**openSUSE** - 企业级和桌面兼顾
- 优点：YaST配置工具强大
- 适合：企业和桌面用户

## Linux目录结构

Linux采用树形目录结构，所有文件和目录都从根目录 `/` 开始。

### 1. 目录结构图

```
/                    根目录
├── bin             基本命令二进制文件
├── boot            启动文件（内核、initrd）
├── dev             设备文件
├── etc             系统配置文件
├── home            用户主目录
│   ├── user1
│   └── user2
├── lib             系统库文件
├── media           可移动媒体挂载点
├── mnt             临时挂载点
├── opt             可选应用软件包
├── proc            进程和内核信息（虚拟文件系统）
├── root            root用户主目录
├── run             运行时数据
├── sbin            系统管理命令
├── srv             服务数据
├── sys             系统设备和内核信息（虚拟文件系统）
├── tmp             临时文件
├── usr             用户程序
│   ├── bin         用户命令
│   ├── lib         库文件
│   ├── local       本地安装的软件
│   └── share       共享数据
└── var             可变数据
    ├── log         日志文件
    ├── cache       缓存数据
    └── tmp         临时文件
```

### 2. 重要目录说明

#### /etc - 配置文件目录

```bash
/etc/passwd          # 用户账户信息
/etc/shadow          # 用户密码信息（加密）
/etc/group           # 组信息
/etc/hostname        # 主机名
/etc/hosts           # 主机名解析
/etc/fstab           # 文件系统挂载配置
/etc/network/        # 网络配置
/etc/ssh/            # SSH配置
/etc/nginx/          # Nginx配置
/etc/systemd/        # systemd配置
```

示例：查看主机名
```bash
$ cat /etc/hostname
ubuntu-server

$ cat /etc/hosts
127.0.0.1 localhost
127.0.1.1 ubuntu-server
```

#### /var - 可变数据目录

```bash
/var/log/            # 系统日志
/var/cache/          # 应用缓存
/var/tmp/            # 临时文件（重启不清空）
/var/www/            # Web服务器文件
/var/lib/            # 应用状态信息
```

示例：查看系统日志
```bash
$ ls -lh /var/log/
-rw-r--r-- 1 syslog adm  45K Dec 23 10:00 syslog
-rw-r----- 1 syslog adm  12K Dec 23 09:50 auth.log
-rw-r--r-- 1 root   root 23K Dec 22 23:59 kern.log
```

#### /home - 用户主目录

每个普通用户都有自己的主目录：

```bash
/home/john/          # john用户的主目录
├── Documents/       # 文档
├── Downloads/       # 下载
├── Pictures/        # 图片
├── Desktop/         # 桌面
└── .bashrc          # bash配置文件（隐藏文件）
```

示例：
```bash
$ cd ~               # 进入当前用户主目录
$ pwd
/home/john

$ ls -la             # 查看所有文件（包括隐藏文件）
drwxr-xr-x 15 john john 4096 Dec 23 10:00 .
drwxr-xr-x  3 root root 4096 Dec 20 15:30 ..
-rw-------  1 john john 2845 Dec 23 09:30 .bash_history
-rw-r--r--  1 john john  220 Dec 20 15:30 .bash_logout
-rw-r--r--  1 john john 3526 Dec 20 15:30 .bashrc
drwxr-xr-x  2 john john 4096 Dec 22 14:20 Documents
```

#### /tmp - 临时文件目录

系统重启时会清空：

```bash
$ cd /tmp
$ echo "temporary data" > test.txt
$ cat test.txt
temporary data
```

### 3. 路径表示

- **绝对路径**：从根目录开始，如 `/home/user/document.txt`
- **相对路径**：从当前目录开始，如 `./document.txt` 或 `../other/file.txt`
- **特殊符号**：
  - `.` 表示当前目录
  - `..` 表示上级目录
  - `~` 表示用户主目录
  - `/` 表示根目录

示例：
```bash
$ pwd
/home/john/Documents

$ cd ..              # 返回上级目录
$ pwd
/home/john

$ cd ~/Downloads     # 进入下载目录
$ pwd
/home/john/Downloads

$ cd /etc            # 使用绝对路径
$ pwd
/etc

$ cd -               # 返回上次所在目录
/home/john/Downloads
```

## 安装Linux

### 1. 安装方式选择

#### 方式1：虚拟机安装（推荐初学者）

**优点：**
- 不影响现有系统
- 可以随时删除
- 支持快照功能

**推荐软件：**
- VirtualBox（免费、开源）
- VMware Workstation Player（免费、功能强大）
- Parallels Desktop（macOS，付费）

#### 方式2：双系统安装

**优点：**
- 性能最佳
- 完整体验

**缺点：**
- 需要分区
- 切换系统需要重启
- 有一定风险

#### 方式3：云服务器

**优点：**
- 随时随地访问
- 真实的服务器环境

**推荐平台：**
- AWS EC2（免费套餐）
- Google Cloud（免费套餐）
- 阿里云、腾讯云（国内）
- DigitalOcean、Vultr

#### 方式4：WSL (Windows Subsystem for Linux)

**优点：**
- 无需虚拟机
- 与Windows无缝集成
- 资源占用少

```powershell
# Windows 10/11 安装WSL
wsl --install
wsl --install -d Ubuntu-22.04
```

### 2. VirtualBox安装Ubuntu步骤

#### 步骤1：下载软件


1. 选择虚拟机，点击"启动"

3. 按照安装向导操作：
   - 选择语言

   - 正常安装
   - 清空磁盘并安装Ubuntu

   - 创建用户账户

## 基本概念

### 1. 用户和权限

Linux是多用户系统，每个用户都有自己的权限：

#### root用户（超级用户）

```bash
# root用户拥有系统的最高权限
# 使用sudo命令以root权限执行命令

$ whoami
john

$ sudo whoami
[sudo] password for john:
root
```

#### 普通用户

```bash
# 查看当前用户信息
$ id
uid=1000(john) gid=1000(john) groups=1000(john),4(adm),27(sudo)

# uid: 用户ID
# gid: 组ID
# groups: 所属的组
```

### 2. 文件权限

Linux文件权限分为三类：所有者、组、其他人

```bash
$ ls -l /etc/passwd
-rw-r--r-- 1 root root 2845 Dec 23 10:00 /etc/passwd
```

权限解析：
```
-rw-r--r--  1  root  root  2845  Dec 23 10:00  /etc/passwd
│  │  │  │  │   │     │     │       │          │
│  │  │  │  │   │     │     │       │          └─ 文件名
│  │  │  │  │   │     │     │       └─ 修改时间
│  │  │  │  │   │     │     └─ 文件大小（字节）
│  │  │  │  │   │     └─ 所属组
│  │  │  │  │   └─ 所有者
│  │  │  │  └─ 链接数
│  │  │  └─ 其他人权限（r--:只读）
│  │  └─ 组权限（r--:只读）
│  └─ 所有者权限（rw-:读写）
└─ 文件类型（-:普通文件，d:目录，l:链接）
```

权限符号：
- `r` (read): 读权限（4）
- `w` (write): 写权限（2）
- `x` (execute): 执行权限（1）

示例：
```bash
# 修改文件权限
$ touch test.sh
$ ls -l test.sh
-rw-r--r-- 1 john john 0 Dec 23 10:30 test.sh

$ chmod 755 test.sh    # rwxr-xr-x
$ ls -l test.sh
-rwxr-xr-x 1 john john 0 Dec 23 10:30 test.sh

$ chmod u+x test.sh    # 给所有者添加执行权限
$ chmod g-w test.sh    # 移除组的写权限
$ chmod o-r test.sh    # 移除其他人的读权限
```

进程是正在运行的程序实例：

### 4. 服务（Service）

服务是在后台运行的进程：


## 终端和Shell

### 1. 什么是终端

终端（Terminal）是用户与Linux系统交互的界面，通过输入命令来操作系统。

**常见终端模拟器：**
- GNOME Terminal (Ubuntu默认)
- Konsole (KDE)
- iTerm2 (macOS)
- Windows Terminal (Windows)

### 2. 什么是Shell

Shell是命令解释器，将用户输入的命令传递给系统内核执行。

**常见Shell：**
- `bash` - Bourne Again Shell（最常用）
- `zsh` - Z Shell（功能强大）
- `fish` - Friendly Interactive Shell（用户友好）
- `sh` - Bourne Shell（最原始）

```bash
# 查看当前Shell
$ echo $SHELL
/bin/bash

# 查看系统可用的Shell
$ cat /etc/shells
/bin/sh
/bin/bash
/bin/rbash
/bin/dash
/usr/bin/zsh
/usr/bin/fish
```

### 3. 命令提示符

```bash
john@ubuntu:~$
│    │      │└─ $ 表示普通用户（# 表示root用户）
│    │      └─ ~ 表示当前目录（主目录）
│    └─ 主机名
└─ 用户名
```

### 4. 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 自动补全命令或文件名 |
| `Ctrl+C` | 终止当前命令 |
| `Ctrl+D` | 退出当前Shell或EOF |
| `Ctrl+L` | 清屏（同clear命令） |
| `Ctrl+A` | 光标移到行首 |
| `Ctrl+E` | 光标移到行尾 |
| `Ctrl+U` | 删除光标前的内容 |
| `Ctrl+K` | 删除光标后的内容 |
| `Ctrl+R` | 搜索历史命令 |
| `↑/↓` | 浏览历史命令 |

示例：
```bash
# 使用Tab自动补全
$ cd /et<Tab>
$ cd /etc/

# 使用Ctrl+R搜索历史
$ <Ctrl+R>
(reverse-i-search)`apt': sudo apt install nginx
```

### 5. 命令历史

```bash
# 查看命令历史
$ history
    1  ls -l
    2  cd /home
    3  pwd
    4  sudo apt update

# 执行历史命令
$ !2              # 执行第2条命令
$ !!              # 执行上一条命令
$ !apt            # 执行最近的以apt开头的命令

# 搜索历史
$ history | grep apt
    4  sudo apt update
   15  sudo apt install nginx

# 清空历史
$ history -c
```

## 初学者常见问题

### 1. 忘记sudo密码

```bash
# 重启进入恢复模式
# 在GRUB菜单选择Advanced options -> recovery mode
# 选择root (Drop to root shell prompt)

# 重新挂载文件系统为读写模式
mount -o remount,rw /

# 修改密码
passwd username

# 重启
reboot
```

### 2. 权限不足

```bash
# 错误示例
$ apt install nginx
E: Could not open lock file /var/lib/dpkg/lock - open (13: Permission denied)

# 正确方式：使用sudo
$ sudo apt install nginx
```

### 3. 找不到命令

```bash
$ nginx -v
bash: nginx: command not found

# 原因1：软件未安装
$ sudo apt install nginx

# 原因2：命令不在PATH中
$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

# 使用绝对路径
$ /usr/local/nginx/sbin/nginx -v

# 或添加到PATH
$ export PATH=$PATH:/usr/local/nginx/sbin
```

### 4. 磁盘空间不足

```bash
# 查看磁盘使用情况
$ df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   48G  500M  99% /

# 查找大文件
$ sudo du -sh /* | sort -hr | head -10

# 清理包缓存
$ sudo apt clean
$ sudo apt autoremove

# 清理日志
$ sudo journalctl --vacuum-time=7d
```

### 5. 如何查看文档

```bash
# 使用man命令查看手册
$ man ls
$ man chmod
$ man bash

# 使用--help参数
$ ls --help
```

## 第一天实践任务

完成以下任务来巩固所学知识：

### 任务1：基本导航

```bash
# 1. 查看当前目录
pwd

# 2. 列出文件
ls -la

# 3. 进入不同目录
cd /etc
cd /var/log
cd ~

# 4. 查看目录树
tree -L 2 ~
```

### 任务2：创建和管理文件

```bash
# 1. 创建目录
mkdir -p ~/practice/day1

# 2. 进入目录
cd ~/practice/day1

# 3. 创建文件
touch file1.txt file2.txt

# 4. 写入内容
echo "Hello Linux" > file1.txt

# 5. 查看内容
cat file1.txt

# 6. 复制文件
cp file1.txt file1_backup.txt

# 7. 重命名文件
mv file2.txt file2_renamed.txt

# 8. 删除文件

```
