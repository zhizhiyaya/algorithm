# Linux 学习计划

## 学习目标

通过系统化的学习，掌握Linux操作系统的核心知识和实践技能，能够熟练使用Linux进行日常开发和系统管理工作。

## 学习路线图

```
基础入门 (2-3周)
    ↓
命令行操作 (3-4周)
    ↓
系统管理 (4-5周)
    ↓
Shell脚本编程 (3-4周)
    ↓
网络与安全 (3-4周)
    ↓
高级应用 (持续学习)
```

## 详细学习计划

### 第一阶段：基础入门 (2-3周)

#### 学习内容
- Linux发展历史和各大发行版介绍
- Linux文件系统结构
- 基本概念：用户、权限、进程
- 安装和配置Linux环境

#### 学习目标
- 了解Linux的基本概念和历史
- 能够独立安装Linux系统
- 理解Linux目录结构

#### 推荐资源
- 文档：[01-基础入门.md](./01-基础入门.md)
- 实践：使用虚拟机安装Ubuntu/CentOS

## 学习建议

### 1. 实践为主
- 每天至少1小时命令行实践
- 搭建自己的Linux环境（虚拟机或云服务器）
- 尝试解决实际问题

### 2. 建立知识体系
- 做好笔记和命令备忘
- 建立自己的命令速查表
- 记录踩过的坑和解决方案

### 3. 参与社区
- 阅读官方文档
- 参与开源项目
- 在Stack Overflow等平台提问和回答

### 4. 定期复习
- 每周复习本周学习内容
- 每月进行知识点总结
- 实践项目巩固知识
