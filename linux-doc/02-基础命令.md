## 文件和目录操作

### 1. ls - 列出目录内容

```bash
# 基本用法
ls                    # 列出当前目录
ls -l                 # 详细信息（长格式）
ls -la                # 包含隐藏文件
ls -lh                # 人类可读的文件大小
ls -ltr               # 按时间排序（最新在最后）

# 示例
$ ls -lh
total 24K
drwxr-xr-x 2 user group 4.0K Dec 23 10:00 Documents
-rw-r--r-- 1 user group  128 Dec 23 09:30 README.md
-rw-r--r-- 1 user group 8.5K Dec 22 15:20 script.sh
```

### 2. cd - 切换目录

```bash
cd /home/user         # 切换到指定目录
cd ~                  # 切换到用户主目录
cd ..                 # 返回上一级目录
cd -                  # 返回上一次所在目录
cd ../../             # 返回上两级目录

# 示例
$ pwd
/home/user/Documents/projects
$ cd ..
$ pwd
/home/user/Documents
$ cd -
/home/user/Documents/projects
```

### 3. pwd - 显示当前目录

```bash
pwd                   # 显示当前工作目录的完整路径

# 示例
$ pwd
/home/user/Documents/myproject
```

### 4. mkdir - 创建目录

```bash
mkdir mydir           # 创建单个目录
mkdir -p a/b/c        # 递归创建多层目录
mkdir dir1 dir2 dir3  # 同时创建多个目录
mkdir -m 755 mydir    # 创建目录并设置权限

# 示例
$ mkdir -p project/{src,test,docs}
$ tree project
project
├── docs
├── src
└── test
```

### 5. rmdir / rm - 删除目录和文件

```bash
rmdir emptydir        # 删除空目录
rm file.txt           # 删除文件
rm -r directory       # 递归删除目录及内容
rm -rf directory      # 强制递归删除（危险！）
rm -i file.txt        # 交互式删除（需确认）

# 示例
$ rm -i important.txt
rm: remove regular file 'important.txt'? y
$ rm -rf temp/
```

### 6. cp - 复制文件和目录

```bash
cp file1.txt file2.txt              # 复制文件
cp file.txt /path/to/destination/   # 复制到指定目录
cp -r dir1 dir2                     # 递归复制目录
cp -p file.txt backup.txt           # 保留文件属性
cp -u source.txt dest.txt           # 只在源文件更新时复制

# 示例
$ cp -r project/ project_backup/
$ cp *.txt /backup/
$ cp -p important.log important.log.bak
```

### 7. mv - 移动/重命名文件

```bash
mv file1.txt file2.txt        # 重命名文件
mv file.txt /path/to/dir/     # 移动文件到目录
mv dir1 dir2                  # 重命名目录
mv *.txt documents/           # 移动所有txt文件

# 示例
$ mv oldname.txt newname.txt
$ mv temp/*.log logs/
$ mv project/ project_v2/
```

### 8. touch - 创建空文件或更新时间戳

```bash
touch newfile.txt             # 创建空文件
touch file1.txt file2.txt     # 创建多个文件
touch -t 202312231200 file.txt # 设置特定时间戳

# 示例
$ touch app.js index.html style.css
$ ls -l
-rw-r--r-- 1 user group 0 Dec 23 10:30 app.js
-rw-r--r-- 1 user group 0 Dec 23 10:30 index.html
-rw-r--r-- 1 user group 0 Dec 23 10:30 style.css
```

## 文件查看和编辑

### 1. cat - 查看文件内容

```bash
cat file.txt                  # 显示文件内容
cat file1.txt file2.txt       # 连接多个文件
cat -n file.txt               # 显示行号
cat > newfile.txt             # 创建新文件（Ctrl+D结束）
cat >> file.txt               # 追加内容到文件

# 示例
$ cat -n script.sh
     1  #!/bin/bash
     2  echo "Hello World"
     3  exit 0
```

### 2. less / more - 分页查看文件

```bash
less file.txt                 # 分页查看（可向前翻页）
more file.txt                 # 分页查看（只能向后）

# less常用快捷键
# Space: 下一页
# b: 上一页
# /pattern: 搜索
# q: 退出

# 示例
$ less /var/log/syslog
$ less +F /var/log/app.log    # 实时查看（类似tail -f）
```

### 3. head / tail - 查看文件开头/结尾

```bash
head file.txt                 # 显示前10行
head -n 20 file.txt           # 显示前20行
tail file.txt                 # 显示最后10行
tail -n 50 file.txt           # 显示最后50行
tail -f /var/log/app.log      # 实时查看日志

# 示例
$ head -n 5 access.log
192.168.1.1 - - [23/Dec/2025:10:00:01] "GET / HTTP/1.1" 200
192.168.1.2 - - [23/Dec/2025:10:00:02] "GET /api HTTP/1.1" 200

$ tail -f app.log             # 实时监控日志
[2025-12-23 10:30:01] INFO: Application started
[2025-12-23 10:30:15] DEBUG: Processing request
```

### 4. nano / vi / vim - 文本编辑器

```bash
nano file.txt                 # 使用nano编辑器
vi file.txt                   # 使用vi编辑器
vim file.txt                  # 使用vim编辑器

# Vim基本操作
# i: 进入插入模式
# Esc: 退出插入模式
# :w 保存
# :q 退出
# :wq 保存并退出
# :q! 不保存退出

# 示例
$ vim config.conf
# 按i进入编辑模式
# 编辑内容...
# 按Esc，输入:wq保存退出
```

## 文本处理

### 1. grep - 文本搜索

```bash
grep "pattern" file.txt       # 搜索包含pattern的行
grep -i "pattern" file.txt    # 忽略大小写
grep -r "pattern" directory   # 递归搜索目录
grep -n "pattern" file.txt    # 显示行号
grep -v "pattern" file.txt    # 显示不匹配的行
grep -c "pattern" file.txt    # 统计匹配行数

# 示例
$ grep -n "error" app.log
42:ERROR: Connection failed
108:ERROR: Invalid input

$ grep -r "TODO" src/
src/main.js:15:// TODO: Implement feature
src/utils.js:82:// TODO: Optimize algorithm

$ ps aux | grep nginx         # 结合管道使用
```

### 2. sed - 流编辑器

```bash
sed 's/old/new/' file.txt           # 替换每行第一个匹配
sed 's/old/new/g' file.txt          # 替换所有匹配
sed -i 's/old/new/g' file.txt       # 直接修改文件
sed -n '10,20p' file.txt            # 打印10-20行
sed '/pattern/d' file.txt           # 删除匹配的行

# 示例
$ sed 's/http/https/g' urls.txt
https://example.com
https://test.com

$ sed -n '5,10p' config.txt         # 只显示5-10行
$ sed -i 's/localhost/0.0.0.0/g' app.conf
```

### 3. awk - 文本分析工具

```bash
awk '{print $1}' file.txt           # 打印第一列
awk '{print $1,$3}' file.txt        # 打印第1和第3列
awk -F: '{print $1}' /etc/passwd    # 指定分隔符
awk '$3 > 100' file.txt             # 条件过滤

# 示例
$ awk '{print $1,$4}' access.log
192.168.1.1 "GET
192.168.1.2 "POST

$ df -h | awk '{print $1,$5}'       # 显示磁盘使用率
Filesystem Use%
/dev/sda1 45%

$ awk -F: '{print $1,$3}' /etc/passwd | head -5
root 0
daemon 1
bin 2
```

### 4. sort - 排序

```bash
sort file.txt                 # 按字母排序
sort -r file.txt              # 逆序排序
sort -n file.txt              # 按数字排序
sort -k2 file.txt             # 按第2列排序
sort -u file.txt              # 去重排序

# 示例
$ cat numbers.txt
10
2
100
20

$ sort -n numbers.txt
2
10
20
100

$ du -sh * | sort -hr         # 按文件大小排序
1.2G videos
450M documents
120M pictures
```

### 5. uniq - 去重

```bash
uniq file.txt                 # 去除相邻重复行
uniq -c file.txt              # 统计重复次数
uniq -d file.txt              # 只显示重复的行

# 示例
$ cat data.txt | sort | uniq
apple
banana
orange

$ cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr
    145 192.168.1.1
     89 192.168.1.2
     12 192.168.1.3
```

### 6. wc - 统计

```bash
wc file.txt                   # 统计行数、词数、字节数
wc -l file.txt                # 只统计行数
wc -w file.txt                # 只统计词数
wc -c file.txt                # 只统计字节数

# 示例
$ wc -l script.sh
125 script.sh

$ find . -name "*.js" | wc -l
42

$ cat article.txt | wc -w
1523
```

### 1. find - 查找文件

```bash
find /path -name "*.txt"              # 按名称查找
```

## 权限管理

### 1. chmod - 修改文件权限

```bash
chmod 755 file.sh             # 设置权限为rwxr-xr-x
chmod +x script.sh            # 添加执行权限
chmod -w file.txt             # 移除写权限
chmod -R 755 directory        # 递归修改目录权限
chmod u+x,g+x file.sh         # 给用户和组添加执行权限

# 权限说明
# r=4, w=2, x=1
# 755 = rwxr-xr-x (所有者全部权限，组和其他人读和执行)
# 644 = rw-r--r-- (所有者读写，组和其他人只读)
# 777 = rwxrwxrwx (所有人全部权限，不安全！)

# 示例
$ ls -l script.sh
-rw-r--r-- 1 user group 256 Dec 23 10:00 script.sh

$ chmod +x script.sh
$ ls -l script.sh
-rwxr-xr-x 1 user group 256 Dec 23 10:00 script.sh

$ chmod 644 config.txt
$ ls -l config.txt
-rw-r--r-- 1 user group 128 Dec 23 10:00 config.txt
```

### 2. chown - 修改文件所有者

```bash
chown user file.txt           # 修改所有者
chown user:group file.txt     # 修改所有者和组
chown -R user:group directory # 递归修改

# 示例
$ ls -l app.log
-rw-r--r-- 1 root root 1024 Dec 23 10:00 app.log

$ sudo chown user:user app.log
$ ls -l app.log
-rw-r--r-- 1 user user 1024 Dec 23 10:00 app.log

$ sudo chown -R www-data:www-data /var/www/html/
```

### 3. chgrp - 修改文件所属组

```bash
chgrp group file.txt          # 修改所属组
chgrp -R group directory      # 递归修改

# 示例
$ chgrp developers project/
$ ls -ld project/
drwxr-xr-x 5 user developers 4096 Dec 23 10:00 project/
```

### 4. umask - 设置默认权限

```bash
umask                         # 查看当前umask值
umask 022                     # 设置umask（文件默认644，目录默认755）
umask 002                     # 设置umask（文件默认664，目录默认775）

# 示例
$ umask
0022

$ umask 002
$ touch newfile.txt
$ ls -l newfile.txt
-rw-rw-r-- 1 user group 0 Dec 23 10:30 newfile.txt
```

## 进程管理

### 1. ps - 查看进程

```bash
ps                            # 显示当前终端进程
ps aux                        # 显示所有进程（详细）
ps -ef                        # 显示所有进程（Unix风格）
ps aux | grep nginx           # 查找特定进程

# 示例
$ ps aux
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root         1  0.0  0.1 169416 11420 ?        Ss   Dec22   0:02 /sbin/init
user      1234  0.5  2.1 789012 87654 ?        Sl   10:00   0:15 node app.js

$ ps aux | grep nginx
root      5678  0.0  0.1  12345  6789 ?        Ss   09:00   0:00 nginx: master
www-data  5679  0.0  0.2  12456  7890 ?        S    09:00   0:05 nginx: worker
```

### 2. top / htop - 实时监控进程

```bash
top                           # 实时显示进程信息
htop                          # 更友好的进程监控工具

# top常用快捷键
# P: 按CPU排序
# M: 按内存排序
# k: 杀死进程
# q: 退出

# 示例
$ top
top - 10:30:15 up 1 day,  2:15,  2 users,  load average: 0.15, 0.25, 0.20
Tasks: 234 total,   1 running, 233 sleeping,   0 stopped,   0 zombie
%Cpu(s):  5.2 us,  2.1 sy,  0.0 ni, 92.5 id,  0.2 wa,  0.0 hi,  0.0 si,  0.0 st
MiB Mem :  16384.0 total,   2048.5 free,   8192.2 used,   6143.3 buff/cache
```

### 3. kill - 终止进程

```bash
kill PID                      # 发送TERM信号（正常终止）
kill -9 PID                   # 发送KILL信号（强制终止）
kill -15 PID                  # 发送TERM信号（同默认）
killall process_name          # 杀死所有同名进程
pkill pattern                 # 按模式杀死进程

# 示例
$ ps aux | grep node
user      1234  5.0  2.1 789012 87654 ?        Sl   10:00   0:15 node app.js

$ kill 1234                   # 正常终止
$ kill -9 1234                # 强制终止

$ killall nginx               # 杀死所有nginx进程
$ pkill -f "python app.py"    # 杀死匹配的进程
```

### 4. bg / fg / jobs - 任务控制

```bash
command &                     # 在后台运行命令
jobs                          # 列出后台任务
fg %1                         # 将任务1调到前台
bg %1                         # 将任务1放到后台
Ctrl+Z                        # 暂停当前任务

# 示例
$ sleep 100 &
[1] 5678

$ jobs
[1]+  Running                 sleep 100 &

$ fg %1
sleep 100
^Z
[1]+  Stopped                 sleep 100

$ bg %1
[1]+ sleep 100 &
```

### 5. nohup - 后台运行不挂断

```bash
nohup command &               # 后台运行，忽略HUP信号
nohup command > output.log 2>&1 &  # 重定向输出

# 示例
$ nohup python app.py &
[1] 6789
nohup: ignoring input and appending output to 'nohup.out'

$ nohup ./long-running-task.sh > task.log 2>&1 &
$ tail -f task.log            # 查看输出
```

## 压缩和解压

### 1. tar - 打包和解包

```bash
tar -cvf archive.tar files    # 创建tar包
tar -xvf archive.tar          # 解包
tar -czvf archive.tar.gz files # 创建gzip压缩包
tar -xzvf archive.tar.gz      # 解压gzip包
tar -cjvf archive.tar.bz2 files # 创建bzip2压缩包
tar -xjvf archive.tar.bz2     # 解压bzip2包
tar -tf archive.tar           # 查看tar包内容

# 选项说明
# c: create创建
# x: extract解压
# v: verbose详细信息
# f: file文件名
# z: gzip压缩
# j: bzip2压缩

# 示例
$ tar -czvf project_backup.tar.gz project/
project/
project/src/
project/src/app.js
project/README.md

$ tar -xzvf project_backup.tar.gz
$ tar -tf project_backup.tar.gz  # 只查看不解压
```

### 2. gzip / gunzip - gzip压缩

```bash
gzip file.txt                 # 压缩文件（原文件被替换）
gzip -k file.txt              # 压缩但保留原文件
gunzip file.txt.gz            # 解压
gzip -d file.txt.gz           # 解压（同gunzip）

# 示例
$ ls -lh
-rw-r--r-- 1 user group 10M Dec 23 10:00 data.txt

$ gzip data.txt
$ ls -lh
-rw-r--r-- 1 user group 2.1M Dec 23 10:00 data.txt.gz

$ gunzip data.txt.gz
```

### 3. zip / unzip - zip压缩

```bash
zip archive.zip files         # 创建zip包
zip -r archive.zip directory  # 递归压缩目录
unzip archive.zip             # 解压
unzip -l archive.zip          # 查看内容
unzip archive.zip -d /path/   # 解压到指定目录

# 示例
$ zip -r website.zip html/
  adding: html/ (stored 0%)
  adding: html/index.html (deflated 65%)
  adding: html/style.css (deflated 72%)

$ unzip -l website.zip
Archive:  website.zip
  Length      Date    Time    Name
---------  ---------- -----   ----
        0  12-23-2025 10:00   html/
     1024  12-23-2025 10:00   html/index.html
      512  12-23-2025 10:00   html/style.css

$ unzip website.zip -d /var/www/
```

## 管道和重定向

### 管道 (|)

```bash
# 将前一个命令的输出作为后一个命令的输入
command1 | command2

# 示例
$ cat access.log | grep "404" | wc -l
42

$ ps aux | grep nginx | awk '{print $2}'
1234
5678

$ ls -l | sort -k5 -n | tail -5    # 找出最大的5个文件
```

### 输出重定向

```bash
command > file                # 覆盖写入文件
command >> file               # 追加到文件
command 2> error.log          # 重定向错误输出
command > output.log 2>&1     # 同时重定向标准输出和错误
command &> all.log            # 同上（简写）

# 示例
$ echo "Hello World" > hello.txt
$ cat hello.txt
Hello World

$ echo "Line 2" >> hello.txt
$ cat hello.txt
Hello World
Line 2

$ ls /nonexistent 2> error.log
$ cat error.log
ls: cannot access '/nonexistent': No such file or directory

$ ./script.sh > output.log 2>&1   # 捕获所有输出
```

### 输入重定向

```bash
command < input.txt           # 从文件读取输入
command << EOF                # Here document
content
EOF

# 示例
$ cat < input.txt

$ mysql -u root -p < backup.sql

$ cat << EOF > config.txt
```

```bash
# 统计访问次数最多的IP
cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -10

# 统计404错误
grep "404" access.log | wc -l

# 找出访问量最大的URL
awk '{print $7}' access.log | sort | uniq -c | sort -nr | head -10

# 统计每小时的访问量
```
